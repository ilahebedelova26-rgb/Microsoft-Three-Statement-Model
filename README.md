# Microsoft-Three-Statement-Model
Three-Statement Financial Forecast &amp; Pro-Forma Model for Microsoft Corporation.
## Project Overview
This project aims to develop an integrated three-statement financial model for Microsoft Corporation.

The model connects the Income Statement, Balance Sheet, and Cash Flow Statement to create a comprehensive financial forecast.
## Model Components

- Income Statement
- Balance Sheet
- Cash Flow Statement
- Financial Forecast
- Pro Forma Financial Analysis

## Tools & Technologies

- Microsoft Excel
- Financial Modeling
- Financial Analysis
